## 1. 보안: 사용자 목록, 권한, 활동 기록에 토큰 필요

(커밋 `40fb7a2`)

v0.4.0 전에는 아래 경로가 토큰 없이 답했습니다. `/server`를 앞에 붙인 형태도 같았습니다.

| 경로 | 드러나던 정보 |
|---|---|
| `/getAllUsers` | 사용자 ID, 이름, 권한 |
| `/getIntents?userId=...` | 아무 사용자의 권한 |
| `/getActivityLog` | 모든 활동 기록(사용자 이름, 파일 이름, 경로) |

이제는 다음 규칙을 따릅니다.

| 경로 | 규칙 |
|---|---|
| `/getAllUsers` | `ADMIN` 권한이 있는 로그인 사용자만 |
| `/getIntents` | 본인 권한, 또는 관리자는 모든 사용자 권한 |
| `/getActivityLog` | 로그인한 사용자 |

익명 요청은 `401`을 받습니다. 관리자가 아닌 사용자가 사용자 목록이나 다른 사람의 권한을 요청하면 `403`을 받습니다. `/server/...` 형태도 같은 규칙을 따릅니다. 사용자 관리, 계정, 활동 화면은 이제 `Authorization: Bearer` 헤더를 보내고, 사용자 목록 요청이 실패하면 화면에 보여 줍니다.

**업그레이드 주의:** 이 경로를 토큰 없이 부르던 스크립트는 이제 토큰을 보내야 합니다.

## 2. Signal 화면

(커밋 `7ac9185`, `26e2c04`, `94a0080`, `11a68dd`, `2378789`, `319e8ce`)

- 어두운 테마만 남깁니다. 밝은 테마와 테마 전환 버튼은 지웠습니다.
- 글꼴을 함께 제공합니다. 본문은 Wanted Sans Variable, 코드와 경로는 JetBrains Mono입니다(Pretendard, FiraD2 대신).
- 배치: 1024 px 이상에서는 64 px 왼쪽 아이콘 레일을 둡니다. 그보다 좁으면 48 px 머리 막대와 메뉴 서랍을 씁니다. 탭 막대 40 px, 상태 막대 28 px, 파일 행 36 px이고 선택한 행에는 2 px 막대가 붙습니다.
- 글자: 본문 14 px, 보조 12 px, 제목 16에서 28 px입니다. 본문 굵기는 550을 유지합니다.
- 모서리: 조작 요소 6 px, 패널 8 px, 칩 4 px입니다.
- 알림(토스트)이 이제 화면에 나옵니다. 이전 버전은 알림을 쌓기만 하고 보여 주지 않았습니다.
- 로고는 막대 세 개 모양을 그대로 두고 라임색으로 바꿨습니다. 파비콘 묶음과 `Docs/images/logo.png`도 같은 모양입니다.
- 모든 화면을 다시 꾸몄습니다. 파일 탐색기(도구 막대, 경로, 목록과 격자, 메뉴, 휴대폰 아래 시트, 세부 정보, 빈 폴더), 빠른 열기, 올리기 패널과 끌어 놓기 덮개, 설정, 계정, 연결된 계정, 사용자 관리, 활동, 시스템, 음악과 동영상 보관함, 이미지, PDF와 Office, 동영상, 오디오, 텍스트 보기(Monaco Signal 테마), 로그인과 Discord, Google 콜백 화면입니다.

모든 기능, 단축키(`Ctrl P`, `Ctrl W`, `Ctrl Tab`, `Ctrl S`), 끌어 놓기, 사각형 선택, 길게 누르기 메뉴는 그대로입니다. 사이드바 접기 버튼은 레일이 대신하므로 지웠습니다. 640 px보다 좁으면 목록에서 수정 시각 열을, 768 px보다 좁으면 종류 열을 숨깁니다. 두 값은 세부 정보 패널에서 볼 수 있습니다.

## 3. 접근성과 터치

(커밋 `e57674f`, `cdc2748`, `96933a1`, `32002b1`, `b171642`, `e4d76eb`)

- 움직임 줄이기: 반짝임과 이퀄라이저가 멈추고, 메뉴, 빠른 열기, 서랍은 120 ms 페이드로 바뀝니다.
- 키보드: 파일 행을 키보드로 열고, 고르고, 메뉴를 띄울 수 있습니다. 탭 닫기 버튼은 초점을 받으면 보입니다. 스크롤 영역 끝에서도 초점 고리가 잘리지 않습니다.
- 터치 화면: 탭, 탭 닫기, 경로, 상태 막대, 세그먼트 버튼, 행이 모두 44 px 이상입니다.
- 도구 막대의 입력 칸과 버튼 높이를 32 px로 맞췄습니다. 업로드 진행과 이퀄라이저는 정보 색을 쓰고, 라임은 조작에만 씁니다.
- 패널 안에서 테두리 상자가 겹치던 곳을 정리했습니다. Discord와 Google 콜백 오류 화면에 "Back to sign in" 버튼을 더했습니다. 빈 곳 메뉴는 창 안에 놓입니다.

시험용 NAS 점검 결과(v0.3.1과 v0.4.0 비교):

| 점검 | v0.3.1 | v0.4.0 |
|---|---|---|
| 가로 스크롤 | 캡처 148개 중 1개 | 149개 중 0개 |
| 글자 대비 4.5:1 미만 | 93쌍 | 0쌍(가장 낮은 값 4.75:1) |
| 키보드 초점 실패 | 232곳 중 74곳 | 234곳 중 0곳(초점 고리 대비 최저 7.39:1) |
| 390 px에서 44 px 미만 터치 목표 | 695개 | 48개 |

남은 48개는 세그먼트 버튼과 스위치입니다. 여백으로 누를 수 있는 영역을 44 px로 넓혔지만, 측정 도구는 보이는 크기만 읽습니다.

## 4. 시험과 시험용 NAS

- `backend/tests/integration/user_listing_test.go`에 새 통합 시험 5개를 더했습니다. 세 경로에 대한 익명, 일반 사용자, 관리자 접근을 확인합니다.
- 통합 시험 준비는 이제 손으로 쓴 스키마 대신 앱의 `db.InitSchema`를 씁니다. 이 덕분에 `TestLocalAuth_*` 시험 2개도 통과합니다.
- 이번 릴리스와 관계없이 v0.3.1과 똑같이 실패하는 시험: `TestSafeJoin_NormalizesRedundantSeparators`, `TestAuthConfig_ReturnsStruct`, `TestReadFolderDetails`, `TestHealthz_ReturnsOK`, `TestTus_ResumeAfterInterruption`, `TestLegacyInput*`(2개).
- `deploy/staging/`에 시험 데이터가 든 시험용 NAS를 `127.0.0.1`에 띄우는 스크립트를 더했습니다(커밋 `89f57da`, `e614fae`).

확인하지 못한 것: Safari, Firefox, 실제 휴대폰, 화면 읽기 프로그램.

## 5. 업그레이드 안내

- 데이터베이스 스키마는 바뀌지 않았습니다. `0.3.1`로 되돌려도 데이터는 그대로 쓸 수 있습니다.
- `/getAllUsers`, `/getIntents`, `/getActivityLog`를 부르는 클라이언트는 Bearer 토큰을 보내야 합니다.
- 밝은 테마는 없어졌습니다. 저장된 밝은 테마 설정은 무시됩니다.
