# Release Notes v0.4.2 (한국어)

> [English version](https://github.com/JMC50/nas/blob/main/Docs/release-notes/v0.4.2.md)

| | |
|---|---|
| 범위 | `v0.4.1..v0.4.2` |
| 커밋 | 릴리스 커밋만 |
| 구성 요소 | 없음(v0.4.1과 같은 코드) |

v0.4.2는 v0.4.1 코드를 다시 게시합니다. `:latest`와 `:0.4` 이미지 태그가 Google 가입 수정이 들어간 빌드를 가리키게 하려는 것입니다.

v0.4.0 이미지 빌드가 멈춰서, v0.4.1을 게시한 뒤에 다시 시작했습니다. 정식 버전 빌드는 끝날 때마다 `:latest`와 `:0.4`를 자기 버전으로 옮깁니다. 그래서 다시 시작한 v0.4.0 빌드가 두 태그를 0.4.0으로 되돌렸습니다. v0.4.2를 마지막에 게시해서 두 태그를 다시 앞으로 옮깁니다.

`:0.4.0`에 고정해 두었다면 `:0.4.2`(또는 `:0.4.1`)로 옮겨 주십시오. v0.4.0에는 v0.4.1에서 고친 Google 가입 문제가 그대로 있습니다.

---

## 업그레이드 안내

- v0.4.1과 코드가 같습니다. 스키마도 바뀌지 않았습니다.
