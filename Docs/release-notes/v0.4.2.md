# Release Notes v0.4.2

> [한국어 버전 / Korean version](https://github.com/JMC50/nas/blob/main/Docs/release-notes/v0.4.2.ko.md)

| | |

| Commits | release commit only |
| Components | none (same code as v0.4.1) |

v0.4.2 republishes the v0.4.1 code so that the `:latest` and `:0.4` image tags point at the build with the Google sign-up fix.

The v0.4.0 image build stalled and was restarted after v0.4.1 had been published. Every non-prerelease build moves `:latest` and `:0.4` to its own version, so the restarted v0.4.0 build moved them back to 0.4.0. Publishing v0.4.2 last moves them forward again.

If you pin `:0.4.0`, move to `:0.4.2` (or `:0.4.1`). v0.4.0 still has the Google sign-up issue fixed in v0.4.1.
