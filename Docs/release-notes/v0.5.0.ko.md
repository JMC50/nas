v0.5.0은 **다운로드 링크**를 더합니다. 링크가 만료되거나 취소될 때까지, 링크를 가진 사람은 로그인 없이 파일이나 폴더 하나를 내려받을 수 있습니다.

---

## 1. 다운로드 링크

(커밋 `8b6fc63`, `8409fba`, `04feef7`, `257f364`, `77cda6c`)

**링크 만들기.** 파일과 폴더의 오른쪽 클릭 메뉴에 "Create download link"가 있습니다. 목록 보기에서는 행마다 링크 버튼도 있고, 휴대폰에서는 ⋮ 메뉴에 있습니다. 대화 상자에서 1시간, 1일, 7일(기본), 30일 중 하나를 고르면 링크와 복사 버튼이 나옵니다. 링크를 만들려면 `DOWNLOAD` 권한이 필요합니다.

**링크 화면.** 왼쪽 레일의 새 "Links" 항목에서 링크마다 파일, 만든 사람, 만료 시각, 내려받은 횟수, 상태를 봅니다. 사용자는 자기 링크를, 관리자는 모든 링크를 보고 취소할 수 있습니다.

**내려받기.** `GET /d/{token}`(`/server/d/{token}` 포함)은 로그인이 필요 없습니다.

- 파일은 `no-store` 첨부 파일로 보냅니다. Range 요청도 됩니다.
- 폴더는 임시 파일 없이 그 자리에서 만든 zip으로 보냅니다.
- 확인에 하나라도 실패하면 자세한 내용 없이 `404`를 돌려줍니다.

**요청마다, 그리고 보내는 동안 다시 확인하는 것:**

- 링크가 만료되거나 취소되지 않았는지 확인합니다.
- 만든 사람이 아직 있고 `DOWNLOAD`(또는 `ADMIN`) 권한이 있는지 확인합니다.
- 대상은 데이터 폴더에 고정한 Go `os.Root`로 엽니다. 내려받는 도중에 파일이나 폴더를 심볼릭 링크로 바꿔치기해도 데이터 폴더 밖에는 닿지 않습니다. 절대 경로 심볼릭 링크는 데이터 폴더 안을 가리켜도 따라가지 않습니다. 데이터 폴더 안에 머무는 상대 경로 심볼릭 링크만 따라갑니다(`Docs/configuration/storage-config.md` 참고).
- 연 파일은 그 핸들로 다시 확인합니다. 일반 파일이어야 하고, FIFO나 장치 파일은 멈추지 않고 `404`를 돌려줍니다.
- 보내는 동안 4 MiB마다, 쓰기 중 250 ms마다, 감시 작업이 1초마다 링크와 만든 사람을 다시 확인합니다. 링크를 취소하거나 만료되면 아주 느리게 받는 연결도 1초 안팎에 끊깁니다. 끝나지 않은 zip은 완성된 파일처럼 닫지 않고 중단합니다.
- 이름이 `.`이나 `..`이거나 `\`가 든 zip 항목은 넣지 않습니다. 그래서 압축을 풀 때 항목이 자기 폴더 밖으로 나갈 수 없습니다.

**제한:**

| 제한 | 값 | 넘쳤을 때 응답 |
|---|---|---|
| 파일 링크 하나의 동시 전송 | 4 | `429`, `Retry-After: 30` |
| 폴더 링크 하나의 zip 전송 | 1 | `429`, `Retry-After: 30` |
| 서버 전체 zip 전송 | 3 | `503`, `Retry-After: 30` |
| 쓰기 시간 제한 | 30초, 쓸 때마다 갱신 | 연결을 닫음 |
| 내려받은 횟수와 활동 기록 | 링크마다 1분에 한 번까지 | |

이 수치는 메모리에만 있으므로 서버를 다시 시작하면 초기화됩니다.

**토큰.** `crypto/rand`로 만든 32바이트이고, URL에 쓸 수 있는 43자입니다. 서버에는 SHA-256 값만 저장합니다.

**활동 기록.** 횟수에 들어간 다운로드는 만든 사람 이름으로 `DOWNLOAD [LINK] AT /경로`를 남깁니다.

## 2. 보안 강화

(커밋 `6e52efe`, `38008d6`, `96f41de`, `cdf3451`, `49c6811`, `348f80f`)

- **접근 기록:** `/d/` 뒤의 토큰과 모든 `token` 쿼리 값을 `REDACTED`로 남깁니다. 기록하는 주소는 해석된 경로와 쿼리로 다시 만들기 때문에, 절대 형식 요청 줄과 퍼센트 인코딩된 키도 가려집니다. 이전 버전은 `?token=<jwt>`를 그대로 기록했습니다.
- **`Content-Disposition`의 파일 이름:** 따옴표 안의 `filename`에는 출력 가능한 ASCII만 남깁니다. 실제 이름은 `filename*`에 그대로 있습니다. 일반 다운로드와 압축 다운로드에도 적용됩니다.
- **SQLite:** 쓰기가 겹치면 바로 실패하지 않고 5초까지 기다립니다(`busy_timeout`).

## 3. 아이콘과 수정

(커밋 `5e68346`, `bf645ac`, `6db9d4c`, `3ffb909`, `d2d0c65`, `6dadc8a`)

- 원본 이미지 하나(`frontend/src/lib/assets/logo-mark.svg`)로 화면 로고, `favicon.svg`, PNG와 ICO 파비콘, `apple-touch-icon.png`, `Docs/images/logo.png`를 만듭니다(`scripts/regen-logos.py`). 아이콘 주소에 버전 값을 붙여서, 브라우저가 저장해 둔 옛 아이콘 대신 새 아이콘을 받아 옵니다.
- 터치 화면에서 머리 막대 버튼의 초점 고리 윗부분이 잘리던 문제를 고쳤습니다. 이제 고리를 안쪽에 그립니다.
- 휴대폰에서 링크 목록의 만료 시각이 중간에 줄바꿈되지 않습니다.
- `deploy/staging/`에서 한 설치 환경에만 맞던 메모를 지웠습니다.

## 4. 업그레이드 안내

- **스키마:** 새 표 `share_links` 하나를 `CREATE TABLE IF NOT EXISTS`로 만듭니다. `0.4.x`로 되돌려도 동작합니다. 이전 버전은 이 표를 무시하고, 기존 링크만 열리지 않습니다.
- **NAS 앞의 리버스 프록시나 SSO 관문:** `/d/`는 로그인 없이 열려야 합니다. 예를 들어 oauth2-proxy에서는 `skip_auth_routes = ["GET=^/d/[A-Za-z0-9_-]{43}$"]`를 씁니다.
- **절대 경로 심볼릭 링크**는 다운로드 링크가 따라가지 않습니다. 공유할 폴더에 심볼릭 링크를 넣어야 한다면 상대 경로로 만드십시오.
- 만든 사람이 `DOWNLOAD` 권한을 잃으면 링크는 목록에 남지만 열리지 않습니다. 권한을 다시 주면 다시 열립니다.
- 여러 연결로 나눠 받는 다운로드 관리자는 파일 링크 하나에 연결 4개를 넘으면 `429`를 받습니다.
