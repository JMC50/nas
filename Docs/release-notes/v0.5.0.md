v0.5.0 adds **download links**: a link that lets anyone download one file or folder without signing in, until it expires or is revoked.

---

## 1. Download links

(commits `8b6fc63`, `8409fba`, `04feef7`, `257f364`, `77cda6c`)

**Creating a link.** "Create download link" is in the right-click menu for files and folders. In list view each row also has a link button; on phones it is in the ⋮ menu. The dialog offers 1 hour, 1 day, 7 days (default) or 30 days and then shows the link with a Copy button. Creating a link needs the `DOWNLOAD` intent.

**Links page.** A new "Links" item in the left rail lists links with file, creator, expiry, download count and state. Users see and revoke their own links; admins see and revoke all links.

**Downloading.** `GET /d/{token}` (also `/server/d/{token}`) needs no sign-in.

- Files are sent as attachments with `no-store`; Range requests work.
- Folders are streamed as a zip built on the fly, with no temporary file.
- Any failed check returns `404` with no detail.

**What is checked on every request, and again while sending:**

- The link is not expired or revoked.
- The creator still exists and still has `DOWNLOAD` (or `ADMIN`).
- The target is resolved through Go's `os.Root` on the data folder, so nothing outside the data folder can be reached, also when a file or folder is swapped for a symlink during a download. Absolute symlinks are never followed, even when they point inside the data folder; relative symlinks that stay inside it are followed (see `Docs/configuration/storage-config.md`).
- The opened file is checked again on its handle: it must be a regular file. FIFOs and devices return `404` instead of blocking.
- While sending, the link and the creator are re-checked every 4 MiB, every 250 ms during writes, and once per second by a watcher. A revoked or expired link stops the transfer within about a second, also for a slow reader. An unfinished zip is aborted, not ended like a complete file.
- Zip entries named `.` or `..`, or containing `\`, are left out, so no entry can escape its folder on extraction.

**Limits:**

| Limit | Value | Answer when full |
|---|---|---|
| Streams per file link | 4 | `429`, `Retry-After: 30` |
| Zip streams per folder link | 1 | `429`, `Retry-After: 30` |
| Zip streams per server | 3 | `503`, `Retry-After: 30` |
| Write deadline | 30 s, renewed on each write | connection closed |
| Download count and activity row | at most once per link per minute | |

The counters live in memory, so they reset when the server restarts.

**Tokens.** 32 random bytes from `crypto/rand`, 43 URL-safe characters. Only the SHA-256 is stored.

**Activity log.** Each counted download writes `DOWNLOAD [LINK] AT /path` under the creator.

## 2. Security hardening

(commits `6e52efe`, `38008d6`, `96f41de`, `cdf3451`, `49c6811`, `348f80f`)

- **Access log:** the token after `/d/` and any `token` query value are written as `REDACTED`. The logged address is rebuilt from the parsed path and query, so absolute-form request lines and percent-encoded keys are masked too. Earlier versions logged `?token=<jwt>` in clear.
- **File names in `Content-Disposition`:** the quoted `filename` keeps printable ASCII only; the real name stays in `filename*`. This applies to normal and archive downloads as well.
- **SQLite:** writes that overlap wait up to 5 seconds (`busy_timeout`) instead of failing at once.

## 4. Upgrade notes

- **Schema:** one new table, `share_links`, created with `CREATE TABLE IF NOT EXISTS`. Rolling back to `0.4.x` keeps working: older versions ignore the table, and existing links stop opening.
- **Reverse proxy or SSO gate in front of the NAS:** `/d/` must stay reachable without sign-in. For oauth2-proxy, for example: `skip_auth_routes = ["GET=^/d/[A-Za-z0-9_-]{43}$"]`.
- **Absolute symlinks** in the data folder are not followed by download links. Use relative symlinks if a shared folder must include them.
- A creator who loses `DOWNLOAD` keeps the links in the list, but they stop opening. Granting `DOWNLOAD` again reopens them.
- Download managers that open many range connections get `429` beyond 4 connections per file link.
