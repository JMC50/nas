v0.7.1은 휴대폰과 태블릿에서 NAS 화면이 깨지거나 누를 수 없던 문제를 고칩니다. 서버는 바뀌지 않으므로 새 설정 없이 올릴 수 있습니다.

---

## 1. 휴대폰과 태블릿 수정

(커밋 `ca8c60c`, `69c6c06`, `09eaf4f`, `fb9b21a`, `f9d3abb`, `ee5c3f0`, `af796c8`, `adedf99`, `da62636`, `75f090f`, `ba9dd62`, `303de4d`, `723cdbb`, `24338c6`)

**미리보기.**

- 이미지와 PDF가 화면에 맞는 배율로 열립니다. 전에는 100%로 열려 왼쪽과 위가 잘리고 스크롤로도 닿지 않았습니다. 배율 표시도 두 줄로 나뉘지 않습니다.
- 동영상 속도 메뉴를 가운데 재생 버튼이 덮지 않고, 낮은 가로 화면에서는 플레이어 안에서 스크롤됩니다. 동영상과 음악의 재생 막대와 음량 막대는 터치 높이가 8px 에서 44px 가 되었습니다. 재생할 수 없는 동영상은 오류 안내만 보입니다.
- 음악 재생 화면은 낮은 가로 화면에서도 제목과 음량 줄이 화면 안에 있습니다.

**터치 화면의 파일 탐색기.**

- 폭 768px 이상의 터치 화면(가로 휴대폰, 태블릿)에서도 한 번 누르면 파일이 열리고, 더보기 버튼, 메뉴의 Select, 여러 개 선택 막대가 좁은 휴대폰처럼 보입니다.
- 길게 누른 뒤 손을 뗄 때 항목이 열리거나 방금 연 메뉴가 닫히지 않습니다.
- 높이 500px 이하의 가로 화면에서는 폴더 제목 줄을 숨겨 목록이 더 많이 보입니다.
- 깊은 폴더에서 경로 줄이 현재 폴더까지 보이도록 스크롤됩니다.

**배치.**

- 메뉴와 공유 링크 대화 상자가 화면 안에 머물고, 화면보다 길면 안에서 스크롤됩니다.
- 빠른 열기에서 긴 파일 이름이 경로를 밀어내지 않습니다.
- 주소창이 보이는 휴대폰에서 로그인 화면 아래쪽이 가려지지 않습니다.
- 좁은 입력 칸의 안내 글자는 잘리는 대신 말줄임표로 끝납니다.
- 탭이 많으면 활성 탭이 보이도록 스크롤됩니다.

**터치 영역과 겹침.**

- 탭 닫기, 권한 스위치, 머리 막대 검색은 터치에서 44px 이상입니다.
- 알림이 항목 메뉴와 업로드 시트의 버튼을 덮지 않고, 한 번에 보이는 개수에 제한이 있습니다.

## 2. 그 밖의 수정

(커밋 `58f09d6`, `64b7f41`, `ec41801`)

- **활동 기록.** 같은 종류의 기록 두 개가 같은 밀리초에 있으면 활동 화면이 "Loading…"에서 멈췄습니다. 이제 보입니다. 여러 파일을 한꺼번에 지우거나 올리면 이런 기록이 생길 수 있습니다.
- **색.** 메뉴와 대화 상자 뒤의 어둡게 덮는 층과 동영상 바탕이 Signal 토큰을 씁니다. 덮는 층의 색은 같습니다. 동영상 바탕은 `#000` 대신 이미지, 코드 화면과 같은 `#090a0d`입니다.
- **동작 줄이기.** 동작 줄이기를 켜면 PDF 쪽 이동이 부드러운 스크롤 없이 바로 넘어갑니다.

---

## 3. 올릴 때 알아 둘 것

- **넓은 터치 화면에서 한 번 누르면 열립니다.** 폭 768px 이상의 터치 화면에서 파일을 누르면 바로 열립니다. 열지 않고 고르려면 더보기 버튼이나 Select 를 쓰십시오.
- **이미지와 PDF는 맞춤 배율로 열립니다.** 100%로 보려면 배율 조절을 쓰십시오.
- **낮은 가로 화면.** 높이가 500px 이하이면 항목 수가 적힌 폴더 제목 줄이 보이지 않습니다.
- **서버 변경 없음.** 서버, API, 데이터베이스, 설정은 v0.7.0 과 같습니다.

---

## 4. 알려진 한계

- 수정은 WebKit 의 터치 흉내로 확인했고 실제 iPhone 이나 iPad 기기로는 확인하지 않았습니다. 주소창 크기가 바뀔 때, 길게 누르기, 안전 영역은 기기에서 확인이 필요합니다.
- 새 폴더, 이름 바꾸기, 삭제는 여전히 브라우저 대화 상자를 써서 Signal 색을 쓸 수 없습니다.
- 격자 보기에는 더보기 버튼이 없고, 메뉴는 길게 눌러 엽니다.
- 터치 화면에서 파일 이동은 끌기로만 됩니다.
- 누른 뒤 그 줄에 hover 배경이 남을 수 있습니다.
